## 1. Identificação do Projeto

Este documento apresenta a documentação formal do projeto desenvolvido para a atividade **“GitHub – Criação de Sites em Nuvem”** na disciplina de Computação em Nuvem.

O desenvolvimento foi realizado de forma colaborativa utilizando um repositório centralizado no GitHub (`PietroSantos280/CNW-SITE-EM-NUVEM`), estruturado com arquivos separados para cada página do site, organização de assets e recursos visuais em pastas, e a utilização de **branches** para registrar a evolução do trabalho de cada integrante.

A ideia do site surgiu a partir de um consenso da equipe: contar a nossa jornada e gostos pessoais através de universos de jogos marcantes que inspiram o grupo, dedicando tempo e criatividade na construção de uma identidade visual única para cada página.

---

## 2. Objetivo

O objetivo principal do projeto foi desenvolver um site dinâmico na nuvem e aplicar, na prática, os conceitos de desenvolvimento web, controle de versão e hospedagem utilizando o Git e o GitHub. A atividade também teve como finalidade demonstrar a organização do trabalho em equipe.

---

## 3. Descrição do Site

O site apresenta uma proposta de imersão na cultura gamer através dos jogos favoritos de cada desenvolvedor. O projeto foi construído para conectar cinco atmosferas visuais distintas:

* **Página Principal (`index.html`):** Apresenta a marca do projeto, o menu global de navegação.

  
* **The Last of Us (pag1.html):** Explora o universo pós-apocalíptico com uma paleta de cores e atmosfera temática sombria e imersiva.
* **The Legend of Zelda (pag2.html):** Explora a essência de aventura e fantasia da franquia através de um design dinâmico.
* **Ghost of Tsushima (pag4.html):** Traz a estética minimalista e elegante inspirada no Japão feudal e na jornada do samurai.

## 5. Organização e Navegação das Páginas

### 5.1. Página Principal – `index.html`

A página principal introduz o projeto, trazendo o contexto da disciplina e apresentando a equipe. O código contém um menu de navegação global que conecta diretamente todas as páginas do site, permitindo navegação fluida e bidirecional em qualquer seção.

### 5.2. Páginas Temáticas – `pag2.html`, `pag3.html`, `pag4.html` e `pag1.html`

A existência de arquivos HTML separados para cada jogo facilita a organização do projeto e permite que cada integrante aplique livremente a paleta de cores e o estilo visual condizente com a sua proposta. Todas as páginas mantêm links de navegação acessíveis para permitir que o usuário vá para qualquer outra página a qualquer momento.

---

## 6. Conclusão

O desenvolvimento do projeto possibilitou a aplicação prática de conceitos de desenvolvimento web e controle de versão em ambiente de nuvem. A utilização de HTML e CSS permitiu construir interfaces ricas e bem estruturadas, enquanto o GitHub foi utilizado com sucesso para armazenar os arquivos, versionar o histórico de alterações através de commits, organizar branches individuais e consolidar a entrega final da equipe.
